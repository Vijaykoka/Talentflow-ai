# Talent Demand Acquisition & Fulfillment (TDAF) Manager Dashboard

A **TDAF Manager Dashboard** in a service-based company should act as a **central command center** to manage:

* Client demands
* Hiring pipeline
* Resource fulfillment
* Vendor coordination
* Bench management
* Interview tracking
* SLA monitoring
* Delivery readiness
* Reporting & analytics

The goal is to provide **end-to-end visibility from demand creation to candidate deployment**.

---

# Core Modules of the Dashboard

## 1. Executive Summary Dashboard

Shows high-level KPIs.

### Widgets

* Total Open Demands
* Closed Demands
* Critical Aging Positions
* Fulfillment %
* Bench Availability
* Active Vendors
* Interviews Scheduled Today
* Offers Released
* Joinings This Week
* Revenue Impact Due to Open Positions

### Charts

* Demand vs Fulfillment Trend
* Skill-wise Demand
* Hiring Funnel
* Vendor Performance
* Resource Utilization

# 2. Demand Management Module

Tracks all client requirements.

## Features

* Create New Demand
* Upload JD
* Define:

  * Skill
  * Experience
  * Budget
  * Location
  * Priority
  * Client
  * Project
  * SLA
* Assign recruiter/vendor
* Track status

## Demand Status Flow

```text
New → Assigned → Sourcing → Screening → Interview → Offer → Closed
```

## Important Fields

| Field        | Example         |
| ------------ | --------------- |
| Demand ID    | DEM-2026-001    |
| Client Name  | ABC Corp        |
| Skill        | Java Full Stack |
| Priority     | Critical        |
| Experience   | 5+ Years        |
| Budget       | ₹18 LPA         |
| Positions    | 5               |
| SLA Due Date | 3 Days          |
